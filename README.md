## 概要

AutoExtracterは、指定したフォルダを監視し、フォルダ内に配置された圧縮ファイルを自動解凍するWindows用の監視アプリです。

ZIP・7z・RARに対応し、一件ずつ解凍します。
パスワードが必要なファイルは優先度を下げ、通常のファイルから処理します。
解凍結果は、完了フォルダ内に圧縮ファイル名から拡張子を除いた名前で保存します。

## インストール方法

1. このリポジトリのReleasesから `AutoExtracter-Setup-x64.exe` をダウンロードして実行します。
2. ライセンスを確認し、インストール先を選択します。
3. 監視フォルダ・完了フォルダ、ショートカットとスタートアップの設定を選択します。
4. 選択内容を確認してインストールします。
5. 完了画面でアプリを起動するか選択し、セットアップを終了します。

初期インストール先は `%LOCALAPPDATA%\AutoExtracter`です。
監視フォルダと完了フォルダを空欄にした場合は、ドキュメント内の `AutoExtracter\Incoming` と `AutoExtracter\Completed` を使用します。

アンインストールはWindowsの「インストールされているアプリ」、またはインストールフォルダ内の `Uninstall.exe` から行います。
スタートアップを利用している場合は削除前にOFFへ変更します。
ユーザー設定・保存済みアイコン・解凍データはアンインストール後も保持します。

## 必要要件

- Windowsの64ビット環境が必要です。
- アンインストーラーの実行には.NET Framework 4.8が必要です。

配布版には.NET 8ランタイムを同梱しているため、.NET 8の別途インストールは不要です。

ソースからビルドする場合はWindowsと.NET 8 SDKを使用し、リポジトリのルートで次を実行します。

```powershell
dotnet build AutoExtracter.csproj -c Release
dotnet run --project AutoExtracter.csproj
```

リポジトリにはアプリのソースと初期設定を含め、インストーラー関連やビルド生成物は含めません。
インストーラーはReleasesで配布します。

## 使用方法

1. AutoExtracterを起動します。
2. 監視フォルダへ圧縮ファイルを置きます。
3. コピー完了を確認すると一時フォルダへ移動し、自動で解凍します。
4. 解凍結果を完了フォルダで確認します。

トレイアイコンの左クリックで通知パネルを開閉し、右クリックで表示します。
すでに起動している場合は、新たに起動すると実行中の通知パネルを表示します。

通知パネルでは、解凍中のファイル名・容量・進捗と待機中のファイルを確認できます。
「監視中：フォルダ名」で監視フォルダを開き、歯車で設定画面を開きます。
電源ボタンでアプリを終了します。

問題マークが表示された場合は、押してエラー・パスワード退避フォルダと当日のログを確認します。
ログは `AutoExtracter-yyyyMMdd.log` にINFO・WARN・ERRORと識別番号を記録します。

## 設定について

処理設定では、監視フォルダ・完了フォルダ、圧縮ファイルの保持、対象拡張子、上限容量、パスワード入力対話モード、スタートアップを設定します。

圧縮ファイルの保持がONの場合は退避先フォルダを指定します。
OFFの場合は退避先の入力欄と参照ボタンを非活性にし、解凍成功後に元の圧縮ファイルを削除します。
設定切替やセクション変更でウィンドウのサイズは変わりません。
上限容量は圧縮ファイル自体の容量をGB単位で指定します。
監視フォルダ・完了フォルダが存在しない場合は、入力中に赤い下線を表示します。

パスワード入力対話モードがONの場合は通知と入力欄を表示します。
入力を待ち始めた後は、入力または退避操作まで後続ファイルの解凍を待ちます。
OFFの場合はパスワード退避フォルダへ移動します。
パスワードを設定ファイルやログへ保存しません。

処理設定は適用時の確認でOKを選択すると保存して再起動します。
Noの場合は保存せず設定画面へ戻ります。
スタートアップは切替時に即時反映します。

外観設定では、ライト・ダーク・システムのテーマカラー、アニメーション、待機中・処理中・対話アイコンを設定します。
アイコンのプレビューを押すとファイルを選択できます。
適用時にGIFをアプリの設定保存先へ取り込むため、元ファイルを削除しても使用できます。
外観設定は適用時に即時反映します。
アニメーションがOFFでも解凍と進捗更新は継続します。

その他ではデスクトップのショートカット作成、インストールフォルダと当日のログを開く操作ができます。
初期設定ボタンは入力値を初期値へ戻します。
適用前にセクションを変更すると、未適用の入力値を保存済みの設定へ戻します。
